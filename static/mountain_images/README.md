# Mountain images

This folder is reserved for the future `mountainQuiz` game (see `CLAUDE.md`) — it isn't built yet, so nothing currently reads from here.

The images that used to live in this folder are real photographs of unconfirmed source/license, so they're gitignored (`mountain_images/*` in `.gitignore`) rather than published to this public repo. This `README.md` is the one file kept out of that rule, just so the folder itself still exists in git.

Before building `mountainQuiz`, either replace these with images you've confirmed are properly licensed (e.g. Wikimedia Commons under a CC license, with attribution), or generate placeholder art the same way `static/fandom_images/` was done for Higher or Lower.
